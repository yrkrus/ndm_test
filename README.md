# AT Command Server for TTY

Реализация тестового задания: сервер на C++17, который прослушивает TTY-устройство (последовательный порт) и отвечает на AT-команды согласно заданному словарю правил.

## Особенности
* **Асинхронный ввод-вывод:** Ожидание данных реализовано через `poll()` без блокировки потока.
* **Настройка TTY:** Порт переводится в "Raw" режим с помощью `termios`, отключено эхо и каноническая обработка.
* **Собственный матчер:** Написан алгоритм сопоставления с образцом (поддержка `.` и `*`) **без использования библиотек регулярных выражений**.
* **Безопасность типов:** Использование `std::string_view`, `enum class` для скоростей порта, запрет копирования дескрипторов (RAII).
* **Чистая архитектура:** Логика разделена на транспорт (`TtyPort`), протокол (`ATServer`), базу правил (`RuleTable`) и логирование (`Logger`).
* **Тестирование:** Покрытие логики (матчер, парсер) юнит-тестами.

## Требования
* ОС: Linux (тестировалось на Fedora / CentOS 8)
* Компилятор: `g++` с поддержкой C++17
* Утилиты: `socat` и `screen` (для эмуляции виртуального последовательного порта при тестировании)
